# Changelog

## 3.0.0

- Introduce separate profiles for any mosque or surau, with editable poster identity, colors, images and independent monthly data.
- Add reusable speaker libraries and editable weekly / nth-weekday lecture rules; preserve manual date overrides when applying rules.
- Add optional per-profile donation QR placement in undated calendar spaces or a footer.
- Replace institution-specific bundled assets and schedules with generic artwork, blank defaults and an optional demonstration profile.
- Lazy-load PNG/PDF export dependencies for A3/A4 output; preserve QR image bytes and include image data in backups.
- Add profile/workspace JSON backup and non-destructive import, calendar/profile regression tests and bilingual documentation.

## 1.0.0

- Initial single-file schedule generator.
